# Переезд интерфейса на React — что сделано и что осталось

Работа идёт в ветке `react-rewrite`. Приложение до самого конца работает на
старом `src/legacyApp.js`: новые компоненты написаны, но ещё не подключены к
`App.tsx`. Переключение и удаление легаси — последний шаг.

Решения, принятые до начала (не пересматриваем):

1. Полный переход на React сразу, без временного моста между старым `ui{}` и
   новым хранилищем.
2. Всё на отдельной ветке; приложение может быть нерабочим в середине.
3. Мёртвый код удаляется по ходу, каждое удаление отдельным коммитом.
4. SCSS, файл рядом с компонентом, обычные (нехешированные) имена классов.
5. Состояние — zustand, серверные данные и опрос — TanStack Query.

---

## Сделано

18 коммитов, 94 модуля на TypeScript, 41 файл стилей, 73 теста.
`npm run typecheck`, `npm test` и `npm run build` проходят.

- **Инфраструктура.** Sass, zustand, TanStack Query, vitest. Скрипты
  `npm test` и `npm run typecheck`.
- **Стили.** `styles.css` на 1968 строк разобран на 41 файл. Собранный CSS
  сверялся со старым подекларационно.
- **Чистка.** Удалены мёртвые стили (старая карточка сканирования, прежний
  просмотрщик, прежняя панель фильтров, `.rail-toggle`, подписи людей на
  плитке) и нерабочая карточка «Пакетная проверка» на экране обучения.
- **Фундамент.** `services/api.ts`, ключи кэша, 53 адреса бэкенда по темам,
  хранилище из одиннадцати слоёв, разбор и сборка адреса, хуки вместо ручной
  привязки обработчиков, `lib/format`, `lib/jobs`, `services/media`.
- **ui-kit.** 19 примитивов и один компонент иконок вместо 44 инлайновых SVG.
- **Каркас.** Боковая и нижняя навигация из одного списка, шапка, меню
  учётной записи, окно входа, уведомления (панель, угол экрана, история).
- **Экраны.** Настройки, Дубликаты, Обучение, Проверка.

### Починено по ходу (не было в плане)

- Две разные анимации назывались `slide`; побеждала вторая, поэтому мерцание
  подгрузки галереи молча не работало.
- «Дубль» тёмной темы оказался не дублем: `@media (prefers-color-scheme: dark)`
  и `:root[data-theme="dark"]` — разные условия. Сведено в примесь.
- `npx tsc --noEmit` вообще не проходил из-за динамического импорта
  немодульного `legacyApp.js` — проверка типов была бесполезной.
- Инлайновые `style="..."` внутри `innerHTML` (отступы дерева папок, ширина
  прогресса карточки устройства, цвет в истории уведомлений) на проде молча
  срезались политикой безопасности `style-src 'self'`. React пишет стили через
  CSSOM, на который она не действует.

Легаси: `legacyApp.js` 2712–3312, разметка — `LegacyShell.tsx`, секция

Стили: `src/styles/views/_scan.scss` (переезжает в `views/scan/`).

- `DeviceCard`, `ProcessingBanner` (баннер уже покрыт `lib/jobs`),
  `FileTree` с отступами через `--depth`, `ScanHistory`, `FeatureList`.
- Диалог добавления устройства и диалог запуска задания.
- **Переделать `collectInventory` (3142–3188).** Сейчас это цикл «поспать
  секунду, дёрнуть `pollStatus()`» до 3600 раз, вложенный в уже идущий
  интервальный опрос. Заменяется на мутацию запуска плюс слежение за
  `device.job.active` в запросе устройств. **Четыре ветки итогового
  сообщения (ошибка / всё ещё идёт / остановлено / готово) портировать
  дословно** — это единственный сигнал пользователю о том, что задание
  молча упало.
- `syncDeviceJobNotifications` (2964–3014) — в отдельный хук, сравнивающий

## Ловушки, о которых нельзя забыть

- **`photoMediaUrl`** уже перенесён и закреплён таблицей-тестом. Любая правка
  правил блюра — сначала строка в таблице, потом код: ошибка здесь означает
  откровенный кадр, показанный без замыливания.
- **Атрибут `hidden` и класс `.hidden` — разные вещи.** Правило: условный
  рендер по умолчанию; класс `.hidden` — только там, где узел обязан остаться
  в DOM ради перехода; атрибут `hidden` — никогда.
- **Никакого CSS-in-JS.** `server.js` отдаёт `style-src 'self'` без
  `unsafe-inline`. `style={{}}` в React безопасен, инъекция `<style>` — нет.
- **StrictMode выполняет эффекты дважды.** У каждого эффекта должна быть
  настоящая уборка: повторный `showModal()` бросает, повторные `observe` и
  `subscribe` удваиваются.
- **`deploy.ps1` делает `npm ci`** — новая зависимость должна попадать в
  `package-lock.json` тем же коммитом.
- Карточки активных задач висят до ручного закрытия, а обычные тосты гаснут
  за пять секунд. Это просьба пользователя, а не недосмотр.

## Как проверять

```bash
npm run typecheck && npm test && npm run build
```

Прод-сборку смотреть через `node server.js`, а не через dev-сервер: только
так всплывают нарушения политики безопасности (`Refused to apply inline
style` в консоли). Для живых данных нужен бэкенд на Windows
(`PHOTO_BACKEND`, токен из `F:\services\homecloud-core\backend-token.txt`).
